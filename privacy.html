최종 수정일: 2026-10-12

이 애플리케이션이 하는 일

이 애플리케이션(이하 "앱")은 운영자가 직접 제작한 영상 콘텐츠를 YouTube Data API v3를 통해 운영자 본인의 유튜브 채널에 업로드하는 용도로만 사용됩니다. 그 외의 기능은 없습니다.

수집하는 개인정보

이 앱은 시청자, 방문자, 또는 제3자로부터 어떠한 개인정보도 수집하지 않습니다. 이름, 이메일, 위치, 기기 정보, 쿠키, 분석 데이터 등을 일체 수집·저장하지 않습니다.

앱이 사용하는 유일한 인증 정보는 운영자 본인이 Google 계정으로 직접 발급한 OAuth 자격 증명(영상 업로드 권한)이며, 이는 운영자 본인의 업로드 작업을 자동화하는 데에만 사용됩니다.

제3자와의 공유

이 앱은 어떠한 개인정보도 제3자에게 공유, 판매, 전송하지 않습니다. 업로드되는 것은 운영자가 직접 제작한 영상 파일과 그 제목·설명·태그뿐이며, 이는 운영자 본인의 유튜브 채널에만 게시됩니다.

사용 범위(Scope)

  • YouTube Data API v3 — 영상 업로드 (youtube.upload) 용도로만 사용
  • 업로드 이외의 읽기/수정/삭제, 시청자 데이터 조회, 댓글·채널 관리 등의 기능은 사용하지 않습니다
